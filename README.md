### 🚀 Featured Projects

* 🧠 **[Mnemosyne](https://github.com/aryandharochh)** — AI-powered RAG-based debugging memory system built with Python, ChromaDB, Cognee, Knowledge Graphs, Git Hooks, and locally hosted Ollama/Llama models. It retrieves historical errors, code context, and solutions to provide context-aware debugging assistance.

* 🎨 **[Pano Projection — 360° Panoramic Graphics Editor](https://github.com/aryandharochh/PanoProjection)** — Unity-based panoramic graphics editor featuring GPU-accelerated painting, non-destructive layer management, perspective-grid snapping, and frame-by-frame animation. Uses custom HLSL shaders, equirectangular projection, N-ary layer hierarchy, onion-skinning, and memory-safe texture allocation.

* 🎮 **[Geometry Dash-Style 2D Platformer](https://github.com/aryandharochh/Geometry-Dash)** — Unity-based rhythm platformer featuring multiple player modes including cube, ball, ship, wave, and spider, with physics-based movement, gravity switching, raycasting, collision handling, and dynamic obstacle interaction.
